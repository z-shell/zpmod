# zpmod startup benchmark

This report compares an identical generated workload across four compilation modes. Lower times are better.

| Mode | Median | p95 | Standard deviation | Relative to plain |
| --- | ---: | ---: | ---: | ---: |
| Plain source | 11.564 ms | 13.331 ms | 0.543 ms | 1.000x |
| zpmod first run | 13.378 ms | 15.495 ms | 0.616 ms | 1.157x |

| Manual .zwc | 3.760 ms | 3.880 ms | 0.099 ms | 0.325x |

## Interpretation

- **Plain source** parses uncompiled files without zpmod.
- **zpmod first run** starts without `.zwc` files and includes automatic compilation cost.
- **zpmod warm** reuses `.zwc` files generated by an earlier zpmod run.
- **Manual `.zwc`** is the native Zsh control, compiled before measurement and loaded without zpmod.

These results describe this synthetic workload and environment. They are not a universal startup-speed claim.
